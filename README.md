**Рассчитай и победи — консольная игра на Go**

Учебный проект с функциями, циклами, вводом пользователя и псевдослучайными числами.

**Правила**

За пять ходов нужно нанести суммарный урон, отличающийся от здоровья противника не более чем на 10. Здоровье противника выбирается в диапазоне 80–120.

| Команда | Урон |
| --- | --- |
| lite | 2–5 |
| mid | 15–25 |
| hard | 30–40 |

Неизвестная команда расходует ход без урона.

**Запуск**

Требуется Go 1.23.0 или новее:

    go run .

Для повтора игры используйте y или Y.

**Проверка**

    go test ./...
